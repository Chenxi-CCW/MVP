Abstract

Token necessity cannot be captured by a single criterion.

Vision-Language Models achieve strong multimodal understanding by encoding images as sequences of visual tokens, yet this dense representation introduces substantial computational overhead. Existing pruning methods often rely on one criterion and therefore capture only a partial view of which tokens are necessary.

We introduce MVP-Token, a two-stage framework that learns token necessity from complementary pruning perspectives. First, MVP-PruneSet collects question-guided, attention-based, and diversity-based masks together with per-sample correctness annotations. Then, MVP-Pruner learns a unified importance score using success–failure-aware soft labels and a ranking-centered objective. Across two model families and eight benchmarks, MVP-Token delivers accurate, interpretable, and efficient visual-token pruning under aggressive budgets.

Method

From diverse evidence to one compact pruner

MVP-Token separates supervision construction from inference. Heterogeneous pruning methods are used only to build supervision; deployment requires a single lightweight scorer.

01

MVP-PruneSet

Collect five aligned masks from three families: GRASP for question-guided grounding, VisPruner for attention, and SCOPE for spatial-semantic diversity. Each mask is paired with whether the frozen VLM still answers correctly after pruning.

02

SFF-Label

Fuse successful and failed masks with reliability-aware family weights. Multi-view agreement raises positive support, while failure evidence suppresses tokens only when successful views do not support them.

03

MVP-Pruner

Project visual and question tokens into a shared space, model spatial context with self-attention, and inject query context through cross-attention. Coarse and fine ranking losses optimize the token order used by top-K selection.

Experiments

Strong retention under aggressive token budgets

Results cover VQAv2, GQA, TextVQA, VizWiz, POPE, ScienceQA, SEED-Bench, and MME. Average scores are normalized to each uncompressed model.
